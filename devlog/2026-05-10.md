1. App.jsx

2. api.js

3. server/index.js

4. api.js

5. App.jsx

## App.jsx の役割

App.jsx では、患者情報を更新するために updatePatient 関数を作っている。

```js
const updatePatient = async (updated) => {
  const savedPatient = await updatePatientApi(updated.id, updated);
  setAppData((prev) => ({
    ...prev,
    patients: prev.patients.map((p) =>
      p.id === savedPatient.id ? savedPatient : p,
    ),
  }));
};
```

重要なのは次の1行。

```js
const savedPatient = await updatePatientApi(updated.id, updated);
```

これは、updated.id の患者を updated の内容でサーバーに保存して、更新済みデータを受け取るという意味。

## api.js の役割

api.js では、実際にサーバーへ PUT リクエストを送る。

```js
export const updatePatientApi = async (id, patient) => {
  const response = await fetch(`${API_BASE}/patients/${id}`, {
    method: "PUT",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(patient),
  });

  if (!response.ok) {
    throw new Error(`API error:${response.status}`);
  }

  return response.json();
};
```

例えば updatePatientApi("abc123", updated) を呼ぶと、PUT http://localhost:3001/api/patients/abc123 が送信される。

## data.json の更新

サーバー側では、受け取った患者データを使って data.json を更新する。

```js
const updatedPatient = {
  ...req.body,
  id,
};

const next = {
  ...data,
  patients: data.patients.map((patient) =>
    patient.id === id ? updatedPatient : patient,
  ),
};

writeData(next);
res.json(updatedPatient);
```

ここで大事なのは2つ。

- writeData(next)
  server/data.json を実際に更新する処理

- res.json(updatedPatient)
  更新した患者データをフロントに返す処理

## 一番大事なつながり

今日一番大事だったのは次の流れ。

```text
res.json(updatedPatient)
  ↓
return response.json()
  ↓
const savedPatient = await updatePatientApi(...)
```

つまり、サーバー側で返した updatedPatient が、api.js の response.json() を通って、App.jsx の savedPatient に入る。

整理すると次のようになる。

```text
server/index.js
res.json(updatedPatient)
  ↓ fetch の response に入る
api.js
return response.json()
  ↓ App.jsx に戻る
App.jsx
const savedPatient = await updatePatientApi(...)
```

## React の state 更新

サーバー保存が成功したあと、React 側の画面データも更新する。

```js
setAppData((prev) => ({
  ...prev,
  patients: prev.patients.map((p) =>
    p.id === savedPatient.id ? savedPatient : p,
  ),
}));
```

これは次の処理。

- 現在の患者一覧を1人ずつ見る
- id が savedPatient.id と一致する患者を探す
- 一致した患者だけ savedPatient に置き換える
- それ以外の患者はそのまま残す

## 今日の理解

まずはこの流れだけで OK。

1. App.jsx
   患者情報を更新したい

2. updatePatientApi を呼ぶ

3. api.js
   サーバーに PUT リクエストを送る

4. server/index.js
   data.json を書き換える
   res.json で返す

5. api.js
   返ってきた JSON を return する

6. App.jsx
   savedPatient に入れて React の state を更新する

## 今日のポイント

- writeData で保存する
- res.json で返す
- return response.json() で api.js から返す
- await で App.jsx が受け取る
- setAppData で画面を更新する
