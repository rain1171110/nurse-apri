# 学習ログ：PatientPageのデータ抽出とProps型の整理

## 今日の学習内容

今日は、`PatientPage.tsx`で現在の患者と、その患者に紐づく看護記録を取り出す処理を確認しました。

また、`PatientPageProps`で`patients`と`records`を直接定義し、操作関数だけを`PatientOutletContext`から`Pick`する理由を整理しました。

---

## 1. URLの患者IDに一致する患者を探す

```ts
const { id } = useParams();

const patient = patients.find(
  (p) => String(p.id) === id,
);
```

`useParams()`で、URLに含まれている患者IDを取得します。

たとえばURLが次の場合です。

```txt
/patient/2
```

`id`には文字列の`"2"`が入ります。

```ts
const patient = patients.find(
  (p) => String(p.id) === id,
);
```

`find()`は、条件に一致する最初の1件を返します。

つまり、この処理では患者一覧の中から、URLの患者IDと一致する患者を1人探しています。

---

## 2. 現在の患者に紐づく看護記録を取り出す

```ts
const patientRecords = records.filter(
  (r) => String(r.patientId) === id,
);
```

この処理で比較しているのは、看護記録自身の`id`ではありません。

比較しているのは次の値です。

```ts
r.patientId
```

`patientId`は、その看護記録がどの患者のものかを示すIDです。

たとえば、次のような記録があるとします。

```ts
const records = [
  {
    id: "101",
    patientId: "1",
    content: "患者1の記録",
  },
  {
    id: "102",
    patientId: "2",
    content: "患者2の記録1",
  },
  {
    id: "103",
    patientId: "2",
    content: "患者2の記録2",
  },
];
```

URLの患者IDが`"2"`の場合、次の条件を満たす記録だけを残します。

```ts
String(r.patientId) === id
```

結果は次のようになります。

```ts
[
  {
    id: "102",
    patientId: "2",
    content: "患者2の記録1",
  },
  {
    id: "103",
    patientId: "2",
    content: "患者2の記録2",
  },
]
```

つまり、`filter()`は一致しない記録を除外し、一致する記録をすべて残します。

---

## 3. `find()`と`filter()`の違い

```ts
const patient = patients.find(
  (p) => String(p.id) === id,
);
```

`find()`は、条件に一致する最初の1件を返します。

患者は現在表示している1人だけ必要なので、`find()`を使います。

```ts
const patientRecords = records.filter(
  (r) => String(r.patientId) === id,
);
```

`filter()`は、条件に一致するものをすべて配列で返します。

1人の患者には複数の看護記録があるため、`filter()`を使います。

```txt
find()
→ 患者を1人探す

filter()
→ その患者の看護記録を複数取り出す
```

## 4. `PatientPageProps`の型

```ts
type PatientPageProps = {
  patients: Patient[];
  records: NursingRecord[];
} & Pick<
  PatientOutletContext,
  | "updatePatient"
  | "updateRecord"
  | "deleteRecord"
  | "deletePatient"
  | "addRecord"
>;
```

この型は、2つの型を`&`で合体しています。

### 患者と記録の元データ

```ts
{
  patients: Patient[];
  records: NursingRecord[];
}
```

`PatientPage`は、患者全員と看護記録全部を親の`App.tsx`から受け取ります。

その後、現在の患者と、その患者の記録をこのファイル内で作ります。

```ts
const patient = patients.find(
  (p) => String(p.id) === id,
);

const patientRecords = records.filter(
  (r) => String(r.patientId) === id,
);
```

### App.tsxから受け取る操作関数

```ts
Pick<
  PatientOutletContext,
  | "updatePatient"
  | "updateRecord"
  | "deleteRecord"
  | "deletePatient"
  | "addRecord"
>
```

次の関数は`PatientPage`内で作るのではなく、`App.tsx`から受け取ります。

```ts
updatePatient
updateRecord
deleteRecord
deletePatient
addRecord
```

すでに`PatientOutletContext`に関数の型が定義されているため、同じ型をもう一度書かずに`Pick`で取り出しています。

---

## 5. `PatientPageProps`を展開した形

現在の型は、実質的には次のような内容です。

```ts
type PatientPageProps = {
  patients: Patient[];
  records: NursingRecord[];

  updatePatient: PatientOutletContext["updatePatient"];
  updateRecord: PatientOutletContext["updateRecord"];
  deleteRecord: PatientOutletContext["deleteRecord"];
  deletePatient: PatientOutletContext["deletePatient"];
  addRecord: PatientOutletContext["addRecord"];
};
```

ただし、同じ関数型を重複して書かずに済むため、`Pick`を使ったほうが管理しやすくなります。

## 6. PatientPage全体の流れ

```ts
import { Outlet, useParams } from "react-router-dom";
import { extractUsedRoomNumbers } from "./Utils";
import type {
  Patient,
  NursingRecord,
  PatientOutletContext,
} from "./types";

type PatientPageProps = {
  patients: Patient[];
  records: NursingRecord[];
} & Pick<
  PatientOutletContext,
  | "updatePatient"
  | "updateRecord"
  | "deleteRecord"
  | "deletePatient"
  | "addRecord"
>;

export default function PatientPage({
  patients,
  records,
  updatePatient,
  addRecord,
  updateRecord,
  deleteRecord,
  deletePatient,
}: PatientPageProps) {
  const { id } = useParams();

  const patient = patients.find(
    (p) => String(p.id) === id,
  );

  const patientRecords = records.filter(
    (r) => String(r.patientId) === id,
  );

  if (!patient) {
    return <div>患者が見つかりません</div>;
  }

  const usedRoomsForEdit = extractUsedRoomNumbers(
    patients,
    patient.id,
  );

  const outletContext: PatientOutletContext = {
    patient,
    patientRecords,
    updatePatient,
    addRecord,
    updateRecord,
    deleteRecord,
    deletePatient,
    usedRoomsForEdit,
  };

  return <Outlet context={outletContext} />;
}
```

処理の流れは次のとおりです。

```txt
App.tsx
↓
patients、records、操作関数をpropsで渡す
↓
PatientPage.tsx
↓
URLのidから現在の患者をfind()で探す
↓
現在の患者の記録をfilter()で取り出す
↓
PatientOutletContextを作る
↓
Outlet contextとして子コンポーネントに渡す
```

---

## 今日の理解

* `find()`は条件に一致する患者を1人探す
* `filter()`は条件に一致する看護記録をすべて残す
* `records.filter()`で比較しているのは記録の`id`ではなく`patientId`
* `patients`と`records`は、現在の患者と記録を作るための元データ
* 操作関数は`App.tsx`から受け取る
* 操作関数の型は`PatientOutletContext`から`Pick`して再利用する
* `PatientPage`で作った値を`Outlet context`として子コンポーネントへ渡す
