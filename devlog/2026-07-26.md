## 1. PostgreSQLのデータ確認

Prisma Studioを起動した。

```bash
npx prisma studio
```

次の3つのテーブルを確認した。

* `Patient`：患者情報
* `NursingRecord`：看護記録
* `VitalSigns`：バイタルサイン

### テーブル同士の関係

```text
Patient
  └─ NursingRecord
       └─ VitalSigns
```

`NursingRecord.patientId`には、関連する患者の `Patient.id`が保存されている。

```text
Patient.id
    ↑
NursingRecord.patientId
```

`VitalSigns.recordId`には、関連する看護記録の `NursingRecord.id`が保存されている。

```text
NursingRecord.id
        ↑
VitalSigns.recordId
```

入力していないバイタル項目は、PostgreSQLでは `NULL`として保存される。

## 2. 患者更新をPrismaへ変更

以前は、次の処理が必要だった。

```text
data.jsonを読み込む
  ↓
対象患者を探す
  ↓
map()で患者配列を作り直す
  ↓
data.jsonへ書き込む
```

Prismaでは、`prisma.patient.update()`がまとめて処理してくれる。

```ts
app.put("/api/patients/:id", async (req, res) => {
  try {
    const { id } = req.params;

    const updatedPatient = await prisma.patient.update({
      where: {
        id,
      },
      data: req.body,
    });

    res.json(updatedPatient);
  } catch (error) {
    console.error("PUT /api/patients/:id error:", error);
    res.status(500).json({ error: "Failed to update patient" });
  }
});
```

### `where`と`data`の役割

```ts
where: {
  id,
}
```

`where`は「どの患者を更新するか」を指定する。

```ts
data: req.body
```

`data`は「どの内容に更新するか」を指定する。

アプリから患者の年齢を変更し、PostgreSQLに反映されることを確認できた。

## 3. 看護記録更新をPrismaへ変更

看護記録本体とバイタル情報は別のテーブルなので、受信データを分ける。

```ts
const { vitals, ...recordData } = req.body;
```

例えば、次のデータを受信した場合、

```ts
{
  patientId: "患者ID",
  date: "2026-07-26",
  author: "岡﨑洋子",
  content: "状態良好",
  vitals: {
    T: 36.5,
    P: 70,
  },
}
```

次のように分けられる。

```ts
vitals;
// {
//   T: 36.5,
//   P: 70,
// }
```

```ts
recordData;
// {
//   patientId: "患者ID",
//   date: "2026-07-26",
//   author: "岡﨑洋子",
//   content: "状態良好",
// }
```

完成した更新処理は次のとおり。

```ts
app.put("/api/records/:id", async (req, res) => {
  try {
    const { id } = req.params;
    const { vitals, ...recordData } = req.body;

    const updatedRecord = await prisma.nursingRecord.update({
      where: {
        id,
      },
      data: {
        ...recordData,
        vitals: {
          upsert: {
            create: vitals,
            update: vitals,
          },
        },
      },
      include: {
        vitals: true,
      },
    });

    res.json(updatedRecord);
  } catch (error) {
    console.error("PUT /api/records/:id error:", error);
    res.status(500).json({ error: "Failed to update record" });
  }
});
```

### `upsert`とは

```ts
upsert: {
  create: vitals,
  update: vitals,
}
```

`upsert`は、次の処理をまとめたもの。

* バイタルが存在する場合：更新する
* バイタルが存在しない場合：新規作成する

## 4. 患者削除をPrismaへ変更

削除では、更新後の内容を渡す必要がない。

そのため、`data: req.body`は使用せず、削除対象を示す `where`だけを指定する。

```ts
app.delete("/api/patients/:id", async (req, res) => {
  try {
    const { id } = req.params;

    await prisma.patient.delete({
      where: {
        id,
      },
    });

    res.json({ id });
  } catch (error) {
    console.error("DELETE /api/patients/:id error:", error);
    res.status(500).json({ error: "Failed to delete patient" });
  }
});
```

### 削除と更新の違い

更新では `where`と`data`が必要。

```ts
await prisma.patient.update({
  where: {
    id,
  },
  data: req.body,
});
```

削除では `where`だけが必要。

```ts
await prisma.patient.delete({
  where: {
    id,
  },
});
```

### レスポンスの形

次のコードでは、IDだけの文字列が返る。

```ts
res.json(id);
```

```json
"32ded91d-..."
```

次のコードでは、`id`プロパティを持つオブジェクトが返る。

```ts
res.json({ id });
```

```json
{
  "id": "32ded91d-..."
}
```

フロントエンドの戻り値型に合わせて、オブジェクトで返す。

```ts
Promise<{ id: string }>
```

## 5. 看護記録削除をPrismaへ変更

```ts
app.delete("/api/records/:id", async (req, res) => {
  try {
    const { id } = req.params;

    await prisma.nursingRecord.delete({
      where: {
        id,
      },
    });

    res.json({ id });
  } catch (error) {
    console.error("DELETE /api/records/:id error:", error);
    res.status(500).json({ error: "Failed to delete record" });
  }
});
```

看護記録を削除すると、関連するバイタルも自動削除される。

これはPrismaスキーマで、次の設定をしているため。

```prisma
onDelete: Cascade
```

この仕組みを「カスケード削除」という。

患者を削除した場合も、関連する看護記録とバイタルが自動削除される。

## 6. JSON保存用コードを削除

以前は、Node.jsのファイル操作機能を使って `data.json`を読み書きしていた。

```text
Express
  ↓
Node.jsのfs
  ↓
data.json
```

現在は、Prismaを通してPostgreSQLを操作している。

```text
Express
  ↓
Prisma
  ↓
PostgreSQL
```

そのため、次のimportが不要になった。

```ts
import { readFileSync, writeFileSync } from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";
import type {
  NursingRecord,
  Patient,
} from "./generated/prisma/client.js";
```

次の型も不要になった。

```ts
type AppData = {
  patients: Patient[];
  records: NursingRecord[];
};
```

`data.json`の場所を作るコードも不要になった。

```ts
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const dataPath = path.join(__dirname, "data.json");
```

ファイルを読み書きする関数も不要になった。

```ts
const readData = (): AppData => {
  const raw = readFileSync(dataPath, "utf-8");
  return JSON.parse(raw) as AppData;
};

const writeData = (data: AppData): void => {
  writeFileSync(
    dataPath,
    JSON.stringify(data, null, 2),
    "utf-8",
  );
};
```

データ全体をJSONへ書き込んでいた `PUT /api/data`も不要になった。

現在は、各データを専用のAPIで操作している。

```text
POST   /api/patients
PUT    /api/patients/:id
DELETE /api/patients/:id

POST   /api/records
PUT    /api/records/:id
DELETE /api/records/:id
```

## 7. 今日理解した重要ポイント

以前は、Node.jsを使用して `data.json`を読み書きしていた。

```ts
readFileSync();
writeFileSync();
```

現在は、PostgreSQLがデータを保存・管理し、Prismaを使ってデータを操作している。

```ts
prisma.patient.findMany();
prisma.patient.create();
prisma.patient.update();
prisma.patient.delete();
```

ただし、Node.js自体を使わなくなったわけではない。

役割は次のとおり。

* Node.js：ExpressやPrismaを動かす実行環境
* Express：フロントエンドからのリクエストを受け取る
* Prisma：TypeScriptからPostgreSQLを操作する
* PostgreSQL：データを実際に保存・管理する

## 9. 完成した `server/index.ts`

```ts
import express from "express";
import cors from "cors";
import { prisma } from "./db.js";

const app = express();
const PORT = process.env.PORT || 3001;

app.use(cors());
app.use(express.json());

app.get("/api/data", async (req, res) => {
  try {
    const patients = await prisma.patient.findMany();

    const records = await prisma.nursingRecord.findMany({
      include: {
        vitals: true,
      },
    });

    const data = {
      patients,
      records,
    };

    res.json(data);
  } catch (error) {
    console.error("GET /api/data error:", error);
    res.status(500).json({ error: "Failed to read data" });
  }
});

app.get("/api/patients", async (req, res) => {
  try {
    const patients = await prisma.patient.findMany();

    res.json(patients);
  } catch (error) {
    console.error("GET /api/patients error:", error);
    res.status(500).json({ error: "Failed to read patients" });
  }
});

app.post("/api/patients", async (req, res) => {
  try {
    const newPatient = await prisma.patient.create({
      data: req.body,
    });

    res.status(201).json(newPatient);
  } catch (error) {
    console.error("POST /api/patients error:", error);
    res.status(500).json({ error: "Failed to create patient" });
  }
});

app.post("/api/records", async (req, res) => {
  try {
    const { vitals, ...recordData } = req.body;

    const newRecord = await prisma.nursingRecord.create({
      data: {
        ...recordData,
        vitals: {
          create: vitals,
        },
      },
      include: {
        vitals: true,
      },
    });

    res.status(201).json(newRecord);
  } catch (error) {
    console.error("POST /api/records error:", error);
    res.status(500).json({ error: "Failed to create record" });
  }
});

app.put("/api/patients/:id", async (req, res) => {
  try {
    const { id } = req.params;

    const updatedPatient = await prisma.patient.update({
      where: {
        id,
      },
      data: req.body,
    });

    res.json(updatedPatient);
  } catch (error) {
    console.error("PUT /api/patients/:id error:", error);
    res.status(500).json({ error: "Failed to update patient" });
  }
});

app.put("/api/records/:id", async (req, res) => {
  try {
    const { id } = req.params;
    const { vitals, ...recordData } = req.body;

    const updatedRecord = await prisma.nursingRecord.update({
      where: {
        id,
      },
      data: {
        ...recordData,
        vitals: {
          upsert: {
            create: vitals,
            update: vitals,
          },
        },
      },
      include: {
        vitals: true,
      },
    });

    res.json(updatedRecord);
  } catch (error) {
    console.error("PUT /api/records/:id error:", error);
    res.status(500).json({ error: "Failed to update record" });
  }
});

app.delete("/api/patients/:id", async (req, res) => {
  try {
    const { id } = req.params;

    await prisma.patient.delete({
      where: {
        id,
      },
    });

    res.json({ id });
  } catch (error) {
    console.error("DELETE /api/patients/:id error:", error);
    res.status(500).json({ error: "Failed to delete patient" });
  }
});

app.delete("/api/records/:id", async (req, res) => {
  try {
    const { id } = req.params;

    await prisma.nursingRecord.delete({
      where: {
        id,
      },
    });

    res.json({ id });
  } catch (error) {
    console.error("DELETE /api/records/:id error:", error);
    res.status(500).json({ error: "Failed to delete record" });
  }
});

app.listen(PORT, () => {
  console.log(`API server running on http://localhost:${PORT}`);
});
```
