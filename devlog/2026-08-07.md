## 2. `getErrorMessage`のユニットテスト

`getErrorMessage`にある3つの分岐をテストした。

```ts
import { describe, expect, it } from "vitest";
import { getErrorMessage } from "./apiError";

describe("getErrorMessage", () => {
  it("Failed to fetchを日本語へ変換する", () => {
    const error = new Error("Failed to fetch");

    const result = getErrorMessage(error, "予期しないエラー");

    expect(result).toBe("サーバーへ接続できません");
  });

  it("通常のErrorなら元のメッセージを返す", () => {
    const error = new Error("看護記録の追加に失敗しました");

    const result = getErrorMessage(error, "予期しないエラー");

    expect(result).toBe("看護記録の追加に失敗しました");
  });

  it("Errorではない値なら予備メッセージを返す", () => {
    const error = "エラー文字列";

    const result = getErrorMessage(error, "予期しないエラー");

    expect(result).toBe("予期しないエラー");
  });
});
```

テスト結果は、3件すべて成功した。

```text
Test Files  1 passed
Tests       3 passed
```

### ユニットテストの基本

```text
準備：テスト用の値を作る
実行：対象の関数を呼び出す
確認：expectで実際の結果と期待結果を比較する
```

### Supertestのインストール

Expressへテスト用のHTTPリクエストを送るため、`supertest`を追加した。


## 4. Expressの`app`をテストから使えるように変更

`server/index.ts`の`app`をexportする。

### 変更前

```ts
const app = express();
```

### 変更後

```ts
export const app = express();
```

これにより、テストファイルからExpressの`app`を読み込める。

```ts
import { app } from "./index.js";
```

### テスト中はサーバーを起動しない

`index.ts`をテストから読み込むと、通常は`app.listen()`も実行される。

そのため、テスト中は3001番ポートでサーバーを起動しないようにする。

```ts
if (process.env.NODE_ENV !== "test") {
  app.listen(PORT, () => {
    console.log(`API server running on http://localhost:${PORT}`);
  });
}
```

通常起動とテスト実行の違いは次のとおり。

```text
通常起動
index.ts
→ app.listen()
→ 3001番ポートで待機

テスト
index.tsからappを読み込む
→ app.listen()は実行しない
→ Supertestがappへ直接リクエストを送る
```

## 次回の学習

次回は、`server/index.test.ts`へ患者APIの統合テストを書くところから再開する。

作成予定のテスト：

```ts
describe("POST /api/patients", () => {
  it("不正な患者データなら400を返す", async () => {
    const response = await request(app)
      .post("/api/patients")
      .send({
        name: "",
        room: 0,
      });

    expect(response.status).toBe(400);
    expect(response.body.error).toBe(
      "Invalid patient data / 無効な患者データ",
    );
  });
});
```

```text
送信データ：
```
