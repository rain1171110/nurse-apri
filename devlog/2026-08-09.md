## 今日理解したこと

### Supertestの役割

Supertestを使うと、ExpressのAPIへテスト用のHTTPリクエストを送り、レスポンスを確認できる。

```ts
const response = await request(app).get("/api/patients");

expect(response.status).toBe(200);
expect(Array.isArray(response.body)).toBe(true);
```

### HTTPメソッドとURLは別の情報

次の2つは同じURLを使用していても、HTTPメソッドが違うため別の処理になる。

```text
PUT /api/patients/:id
DELETE /api/patients/:id
```

`PUT`や`DELETE`はURLの中に書かれるのではなく、リクエストのHTTPメソッドとして指定される。

### NODE_ENVによるサーバー起動の制御

テスト中に通常のサーバーまで起動しないように、次の条件を追加した。

```ts
if (process.env.NODE_ENV !== "test") {
  app.listen(PORT, () => {
    console.log(`Server is running on port ${PORT}`);
  });
}
```

Vitestの実行中は`NODE_ENV`が`test`になるため、`app.listen()`は実行されない。

### DB接続エラーについて

テスト中、一時的にPostgreSQLとの接続が切れ、次のエラーが発生した。

```text
Connection terminated unexpectedly
ECONNREFUSED
```

これはテストの期待値が間違っているのではなく、PrismaからPostgreSQLへ接続できていないことが原因だった。

Zodの入力チェックだけで終了するテストはDBへ接続しないため成功するが、Prismaを使用するテストはDB接続が必要になる。
