## 理解したこと

`PatientList` の「追加」ボタンを押すと、`AddPatientForm` が表示される。フォーム内の見出しは「患者を追加」、ボタンは「保存」「キャンセル」。

存在しない要素の確認には `queryByRole`、描画済みの要素の確認には `getByRole` を使う。

```tsx
// フォームが表示されない
expect(
  screen.queryByRole("heading", { name: "患者を追加" }),
).not.toBeInTheDocument();

// フォームが表示される
expect(
  screen.getByRole("heading", { name: "患者を追加" }),
).toBeInTheDocument();
```

モック関数が呼ばれたか調べるときは、関数を実行せず、関数そのものを `expect` に渡す。

```tsx
const setShowAddForm = vi.fn();

// キャンセルボタンをクリックした後
expect(setShowAddForm).toHaveBeenCalledWith(false);
```
