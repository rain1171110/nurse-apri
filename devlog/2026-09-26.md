## 理解したこと

- `onSubmit` に渡る `room` は数値。画面の `TextField` に入力された値は文字列。
- `optionalNumber` の `Number(v)` が `"999"` を `999` に変換する。
- 空欄はスキーマ内で `undefined` になり、部屋番号の必須チェックでエラーになる。
- `.transform((value) => value as number)` の `as number` は型の指定であり、実際の値を変換しない。
- 今の部屋番号欄は `type="number"` を指定していないため、リセット後の入力欄は `toHaveValue("")` で確認する。
- `await user.click(...)` はクリック操作を待つ。保存後の非同期な画面更新は `waitFor` で待つ。

## 保存成功後のリセットを確認したコード

```tsx
it("保存成功したら、フォーム内容リセットする", async () => {
  const onSubmit = vi.fn().mockResolvedValue({
    id: "testId",
    name: "testName",
    room: 999,
  });
  const onErrorsChange = vi.fn();
  const setShowAddForm = vi.fn();
  const user = userEvent.setup();

  render(
    <AddPatientForm
      patients={[]}
      onSubmit={onSubmit}
      showAddForm={true}
      setShowAddForm={setShowAddForm}
      onErrorsChange={onErrorsChange}
    />,
  );

  const nameInput = screen.getByLabelText("氏名");
  const roomInput = screen.getByLabelText("部屋番号");

  await user.type(nameInput, "testName");
  await user.type(roomInput, "999");
  await user.click(screen.getByRole("button", { name: "保存" }));

  expect(onSubmit).toHaveBeenCalledWith({
    name: "testName",
    room: 999,
  });

  await waitFor(() => {
    expect(nameInput).toHaveValue("");
    expect(roomInput).toHaveValue("");
  });
});
```

※ `waitFor` は `@testing-library/react` から import する。
