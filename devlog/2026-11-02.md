## 3. 実装・技術の要点

- 重要なコードまたはコマンド：

```tsx
const patientRecordsGraph = [...patientRecords];

patientRecordsGraph.sort(
  (a, b) => Date.parse(a.date) - Date.parse(b.date),
);

const patientRecordsWithTemperature = patientRecordsGraph.filter(
  (r) => r.vitals?.T != null,
);

const temperatureGraphData = patientRecordsWithTemperature.map((r) => ({
  date: r.date,
  temperature: r.vitals?.T,
}));
```

- 責務・目的：
  - `patientRecordsGraph`：元配列をコピーし、日付順に並べ替える。
  - `patientRecordsWithTemperature`：体温が`null`または`undefined`でない記録に絞る。
  - `temperatureGraphData`：記録を`{ date, temperature }`の形に変換する。
- 入力：`patientRecords`（患者の看護記録配列）
- 出力：日付順の`{ date, temperature }`データ配列
- 副作用：
  - `.sort()`は呼び出した配列を並べ替える。今回はコピーした`patientRecordsGraph`に対して使うため、元の`patientRecords`の並びは保つ。
  - `.filter()`と`.map()`は新しい配列を返す。戻り値を変数に保存して使う。
- 型の絞り込み：SVG描画時に`if (item.temperature == null) return null;`とする。以降の座標計算では`temperature`が数値であることを確認できる。
- null／undefinedの扱い：`r.vitals?.T != null`は`null`と`undefined`を除外し、`0`は残す。描画側でも未設定なら点を描かない。
- 型で守れていること：`T`は省略可能なので、グラフ描画前に値の有無を確認する必要がある。型チェックは未実施。
- 似た書き方との違い：
  - `if (T)`では`0`も偽として扱われる。
  - `T != null`では`0`は残り、`null`と`undefined`だけを除外する。
  - `.sort()`は配列を並べ替える。`.filter()`と`.map()`は結果の新しい配列を返す。
- 今日理解したこと：
  - `Date.parse()`で日付文字列を比較用の数値に変換できる。
  - 日付の最初と最後を使い、日付間隔に応じてx座標を計算する。
  - 体温34℃を`y=260`、42℃を`y=20`とする式で、SVGの縦座標に変換する。
  - SVGではyの数値が小さいほど画面上部に表示される。
- 改善余地：
  - 現在は点のみで、点をつなぐ線はまだない。
  - 縦軸の34〜42℃は固定値。範囲外の体温はグラフ領域から外れる可能性がある。
  - 日付だけをx座標に使うため、同日付の複数記録は同じ位置に重なる可能性がある。
  - 軸の数値目盛り・日付ラベル・画面幅対応は未実装。

```tsx
<svg viewBox="0 0 600 300" role="img" aria-label="体温の推移">
  <line x1="40" y1="260" x2="580" y2="260" stroke="currentColor" />
  <line x1="40" y1="20" x2="40" y2="260" stroke="currentColor" />

  {temperatureGraphData.map((item, index) => {
    const currentDate = Date.parse(item.date);
    const x =
      graphStartDate === graphEndDate
        ? 310
        : 40 +
          ((currentDate - graphStartDate) /
            (graphEndDate - graphStartDate)) *
            540;

    if (item.temperature == null) return null;

    const y = 260 - ((item.temperature - 34) / 8) * 240;

    return (
      <circle
        key={`${item.date}-${index}`}
        cx={x}
        cy={y}
        r="4"
        fill="currentColor"
      />
    );
  })}
</svg>
```

- `viewBox="0 0 600 300"`：SVG内の座標範囲を指定する。
- 横軸：`x=40`から`x=580`、`y=260`に引く。
- 縦軸：`x=40`、`y=20`から`y=260`に引く。
- x座標：日付の開始と終了の間で、経過時間に応じて`40`から`580`へ配置する。開始日と終了日が同じ場合は中央の`310`にする。
- y座標：34〜42℃の値を`y=260`から`y=20`に変換する。38℃は`y=140`になる。
- `<circle>`：1件分の記録を点として描画する。
- `key`：同じ日付の記録があってもReactが識別できるよう、日付と配列番号を組み合わせる。
