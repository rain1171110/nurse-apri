## 追記：`sort` と `localeCompare()` の理解

### 比較関数が返す値

`Array.prototype.sort()` は配列を並べ替える。比較関数には比較対象の2件 `a` と `b` が渡され、戻り値で順番を伝える。

- 負の数：`a` を `b` より前にする
- 正の数：`a` を `b` より後ろにする
- `0`：同じ順序として扱う

戻り値は要素に付ける番号ではなく、並び順を伝えるための値。現行のJavaScriptでは安定ソートが保証されており、比較結果が `0` の要素は元の相対順序を保つ。

### 日付と時刻の比較

```ts
patientRecordsGraph.sort((a, b) => {
  const dateOrder = Date.parse(a.date) - Date.parse(b.date);
  if (dateOrder !== 0) return dateOrder;

  if (!a.time && b.time) return 1;
  if (a.time && !b.time) return -1;
  if (a.time === b.time) return 0;
  if (a.time && b.time) return a.time.localeCompare(b.time);

  return 0;
});
```

- `dateOrder` は、比較中の2件の日付をミリ秒に変換して引いた数値。
- 日付が異なる場合は、その差を返して日付順を決める。負なら `a` が先、正なら後。
- 日付が同じ場合は、時刻で並べる。
- 時刻がない記録は、時刻がある記録より後ろに置く。
- 時刻が同じ、または両方未設定なら `0` を返す。
- 両方に時刻があれば `localeCompare()` の結果で比べる。

`[...patientRecords]` で配列をコピーしてから `.sort()` すると、元の `patientRecords` を直接並べ替えずに済む。`.sort()` 自体は呼び出した配列を変更する。

### `localeCompare()` の役割

`localeCompare()` は文字列同士を比較して、負の数・正の数・`0` を返すメソッド。時刻専用ではなく、今回のコードでは `a.time` と `b.time` を渡しているため時刻比較に使われている。

```js
"08:15".localeCompare("09:00"); // 負の数
"09:00".localeCompare("08:15"); // 正の数
"09:00".localeCompare("09:00"); // 0
```

ゼロ埋めされた `HH:mm` 形式は文字列順が時刻順と一致する。`localeCompare()` 単体は比較結果を返すだけで、配列を並べ替えない。配列の並べ替えは `.sort()` が行い、その比較関数の中で `localeCompare()` の結果を使う。
