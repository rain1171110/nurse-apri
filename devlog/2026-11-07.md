## 3. 実装・技術の要点

- 重要なコードまたはコマンド：

```tsx
const patientRecordsWith = patientRecordsGraph.filter(
  (r) => r.vitals?.T != null || r.vitals?.P != null,
);

const GraphData = patientRecordsWith.map((r) => ({
  recordKey: r.id,
  xDate: Date.parse(r.date),
  date: r.date,
  label: `${r.date} ${r.time || "時刻未記録"}`,
  temperature: r.vitals?.T,
  pulse: r.vitals?.P,
}));
```

```tsx
<XAxis
  dataKey="xDate"
  type="number"
  scale="time"
  domain={["dataMin", "dataMax"]}
  tickFormatter={(value) => {
    const date = new Date(value);
    return `${date.getUTCMonth() + 1}/${date.getUTCDate()}`;
  }}
/>
```

- 責務・目的：
- `filter()`：体温または脈拍のどちらかが記録された行を残す
- `map()`：Rechartsが使う`recordKey`、`xDate`、Tooltip用`label`、体温、脈拍を作る
- `XAxis`：`xDate`を時系列上の位置に使い、目盛りには月/日を表示する
- `YAxis`と`Line`：`yAxisId`で体温軸・脈拍軸と各線を対応させる
- 入力：`patientRecordsGraph`内の看護記録と各記録のバイタル値
- 出力：Recharts用のグラフデータ配列と、日付を使ったグラフ表示
- 副作用：`Date.parse()`は元の`r.date`を書き換えない。`xDate`用の数値を返す
- 型の絞り込み：`r.vitals?.T != null || r.vitals?.P != null`で、体温または脈拍が存在する記録を対象にする
- null／undefinedの扱い：値が`null`または`undefined`の項目は、データ行にそのまま`undefined`として入り得る。Tooltipの`label`では時刻がなければ`時刻未記録`を使う
- 型で守れていること：未確認
- 似た書き方との違い：
- `r.vitals?.T || ...`は値の真偽で判定するため、`!= null`による存在確認と異なる
- `tickFormatter`は目盛り表示を変える。グラフ上の点の座標は`dataKey`の値で決まる
- `recordKey`は記録識別用、`xDate`は横軸位置用、`label`はTooltip表示用
- 今日理解したこと：
- `Date.parse(r.date)`は日付文字列からミリ秒単位の数値を返し、元の文字列は変更しない
- 数値の時間軸では日付間隔を横位置に反映できる
- `getUTCMonth()`は0始まりなので、月表示には`+ 1`が必要
- 同じ日に複数記録がある場合、日付だけの`xDate`では同じ横位置になる
- 改善余地：同日付内の時刻順の配置、同じ日時の点の重なり、表のソート、右Y軸ラベルの余白を確認する

## 5. 質問・つまずきと再発防止

- 質問したこと：
- 体温と脈拍を別グラフにするか、一つのグラフにまとめるか
- X軸を記録ごとではなく日付にできるか
- `Date.parse(r.date)`は文字列を数値に変換するのか
- 年を表示せず月/日だけにできるか
- つまずいた現象：
- `filter()`でカンマを使って体温と脈拍を並べようとした
- 脈拍値を`temperature`キーに入れていた
- Y軸と線を`dataKey`で結び付けようとした
- `tick`と`tickFormatter`の役割を混同した
- `tickFormatter`の引数に`(r.date)`を指定しようとした
- 直接原因：
- 条件をつなぐ演算子、データ行のキー名、軸ID、フォーマッター関数の引数の役割が曖昧だった
- 根本原因（知識／確認／考え方など）：Rechartsの各プロパティが「データ値」「軸の識別」「表示形式」のどれを担当するかの整理が不足していた
- 最終的に理解したこと：
- 体温または脈拍の存在確認には`||`とそれぞれの`!= null`を使う
- `yAxisId`で各Y軸と`Line`を結び付ける
- `tickFormatter`は値を受け取る関数で、`XAxis`の`dataKey`に応じた値が引数に渡る
- `Date.parse()`で日付を数値化し、`Date`からUTCの月・日を取り出して表示できる
- 次回の切り分け手順：
1. 何が起きたかを言葉にする
2. 関係する値・設定・ファイルを確認する
3. 原因候補を絞る
4. 修正または対応後に確認する
- 再発防止ルール：Rechartsのプロパティを変更するとき、データキー・軸ID・表示フォーマッターの役割を分けて確認する
