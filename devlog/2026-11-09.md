## 3. 実装・技術の要点

- 重要なコードまたはコマンド：

```tsx
itemSorter={(item) => {
  const order = ["体温", "脈拍", "SBP", "DBP", "呼吸", "SPO2"];
  const index = order.indexOf(String(item.name));

  return index === -1 ? order.length : index;
}}
```

- 責務・目的：Tooltipの各項目に、表示順として使う数値を返す
- 入力：Tooltip項目の`item.name`
- 出力：`order`配列内の位置。名前が見つからない場合は`order.length`
- 副作用：なし
- 型の絞り込み（該当する場合）：カスタムドットの座標が`null`または`undefined`なら`<g />`を返す
- null／undefinedの扱い（該当する場合）：カスタムドットの`cx`・`cy`が未設定の場合は描画しない
- 型で守れていること：`DotItemDotProps`を使い、カスタムドットの引数型を指定
- 似た書き方との違い：`indexOf()`は要素の位置を返す。見つからない場合は`-1`を返す。`String()`は名前を文字列に変換する
- 今日理解したこと：
  - `order`配列の位置をTooltipの並び順として使える
  - 配列の位置は0から始まり、`indexOf()`の`-1`は対象が見つからないことを表す
  - `order.length`は配列の要素数を返す。今回の6項目なら、未登録名の順位は数値の`6`になる
  - 現在の6つのLine名が`order`と一致していれば、`-1`の分岐は通常使われない
  - Tooltipの既定は`name`順で、Lineの記述順とは別に並ぶ
- 改善余地：画面幅が狭い場合、時刻未記録、同じ日時の複数記録の表示確認が残っている
