## 3. 理解に苦しんだポイント

### ❓ 疑問1：payload は何から来るのか？
```
「グラフをクリック」→「Rechartsが情報をくれる」
この部分が最初は繋がらなかった
```

**理解した**：
- LineChart は子コンポーネント（Tooltip）を持つ
- LineChart がクリックを検知 → 子に情報を渡す
- Tooltip は `trigger="click"` で「クリック情報をくれたら反応する」と宣言
- `content={({ active, payload }) => { ... }}` で情報をもらう

### ❓ 疑問2：!payload?.length がなぜデータの有無を判定するのか？
```
payload.length = 個数を数える
!payload?.length = 「個数が0か、payload が null か」
```

**理解した**：
- `.length` は配列の要素数を返す
- `?.` は「null だったら安全に止まって」という保険
- 個数が0 = データがない = `!payload?.length` は true

## 4. コードと理解したこと

### 最終的なコード

```jsx
<Tooltip
  trigger="click"
  content={({ active, payload }) => {
    // ステップ1: Tooltipが表示されるべきか判定
    if (!active || !payload?.length) return null;

    // ステップ2: クリック位置のデータを取得
    const activePoint = payload[0]?.payload;
    if (!activePoint) return null;

    // ステップ3: 同じ日時のすべての記録を取得
    const records = getRecordsAtXDate(activePoint.xDate);
    
    // ステップ4: クリックされた記録IDを取得
    const clickedRecordKey = payload[0]?.payload?.recordKey;
    
    // ステップ5: クリックされた記録だけをフィルタリング
    const filtered = records.filter(
      (r) => r.recordKey === clickedRecordKey,
    );

    // ステップ6: Tooltip を表示
    return (
      <div style={{ background: "white", border: "1px solid #ccc", padding: 8 }}>
        {filtered.map((r) => (
          <div
            key={r.recordKey}
            style={{
              marginBottom: 8,
              paddingBottom: 8,
              borderBottom: "1px solid #eee",
            }}
          >
            {/* 日時とID（太字） */}
            <div style={{ fontWeight: "bold", marginBottom: 4 }}>
              {r.label} (ID:{String(r.recordKey).slice(0, 8)})
            </div>
            
            {/* バイタルデータ5行 */}
            <div style={{ fontSize: 12, lineHeight: 1.6 }}>
              <div>体温: {formatValue(r.temperature, "℃")}</div>
              <div>脈拍: {formatValue(r.pulse, "回/分")}</div>
              <div>呼吸: {formatValue(r.respiration, "回/分")}</div>
              <div>血圧: {formatBpText(r.systolicBloodPressure, r.diastolicBloodPressure)}mmHg</div>
              <div>SPO2: {formatValue(r.saturation, "%")}</div>
            </div>
          </div>
        ))}
      </div>
    );
  }}
/>
```

### 解説メモ

**質問・テーマ**：
- グラフをクリック → Tooltip に情報がどうやって渡されるのか
- 同じ日時の複数記録を区別するには

**重要な処理の流れ**：
1. ユーザーがグラフの系列をクリック
2. LineChart が「クリックされた」と認識
3. LineChart が子（Tooltip）に `active` と `payload` を渡す
4. `payload[0]?.payload?.recordKey` でクリックされた記録IDを抽出
5. `.filter()` で同じ日時の記録から、クリックされた記録だけを抽出
6. 抽出された記録（1件）のバイタルデータを表示

## 5. 自分の理解

### このコードの役割
グラフ上の任意の系列（体温、脈拍など）をクリック → クリックされた系列のデータを持つ記録だけを Tooltip に表示

### 入力と出力
**入力**：
- ユーザーのクリック操作
- GraphData（グラフ用に加工された記録データ）

**出力**：
- Tooltip に表示される情報（クリックされた記録1件分）

### 重要な処理の流れ
```
クリック操作
  ↓
payload から clickedRecordKey を抽出
  ↓
records.filter() で clickedRecordKey に合致する記録を抽出
  ↓
filtered（1件だけ）を map で表示
```

### 今回、自分で変更したところ
- `const filtered = records.filter((r) => r.recordKey === clickedRecordKey)` を追加
- `records.map` を `filtered.map` に変更
- その他は Copilot の指導のコードを実装

### 修正後の変化
- Tooltip に複数の記録が表示される状態 → クリックされた記録1件だけ表示
- ユーザーは「どの系列がクリックされたのか」を視覚的に判定できるようになった

### 理解したこと
- **親子コンポーネントの情報伝達**：親が子に情報を渡す仕組み
- **配列のフィルタリング**：`.filter()` で条件に合致する要素だけを抽出
- **Recharts の仕組み**：クリックされた系列の情報が `payload[0]?.payload?.recordKey` に入っている

### 次に確認したいこと
- 実際にローカル画面で、異なる系列をクリックして、記録が正しく切り替わるか確認
- エラーが出ていないか確認
- 同じ日時の複数記録がない場合でも正常に動作するか確認
