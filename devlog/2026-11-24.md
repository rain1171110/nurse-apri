**ファイル：src/PatientVitals.tsx（子2）**

```typescript
type PatientVitalsOutletContext = Pick<
  PatientOutletContext,
  "patient" | "patientRecords"
>;

const { patient, patientRecords } = useOutletContext<PatientVitalsOutletContext>();
```

**重要なポイント：**

```
【親が配る】

  ↓
<Outlet context={outletContext} />

【子が選んで受け取る】
PatientMenu は「patient と deletePatient」だけ受け取る
PatientVitals は「patient と patientRecords」だけ受け取る
  ↓
「Pick」で必要な部分だけ抽出
```

**なぜ Pick を使うのか？**

```
理由1：「この子に何が必要か」を明確にする
理由2：「不要なデータは受け取らない」という意図を示す
理由3：TypeScript で型チェックできる
```

### 【深掘り3：バイタルグラフのデータ加工フロー】

**フロー全体：**

```
patientRecords（元のデータ）
  ↓
const patientRecordsGraph = [...patientRecords];
  ↓ コピーを作成

patientRecordsGraph.sort();
  ↓ 日付順、時刻順にソート

const patientRecordsWith = patientRecordsGraph.filter();
  ↓ vitals がある記録だけ抽出

const GraphData = patientRecordsWith.map();
  ↓ グラフが使える形に変換

GraphData（グラフが表示可能な形）
```

#### ステップ1：ソート処理

**日付のソート：**

```typescript
const dateOrder = Date.parse(a.date) - Date.parse(b.date);
if (dateOrder !== 0) return dateOrder;
```

```
【返り値の意味】
負数（-1）→ a が前に来る（a < b）
0        → 順序変わらず
正数（1） → b が前に来る（a > b）
```

**時刻のソート（日付が同じ場合のみ実行）：**

```typescript
if (!a.time && b.time) return 1;        // 時刻がない → 後ろ
if (a.time && !b.time) return -1;       // 時刻がある → 前
if (a.time === b.time) return 0;        // 同じ時刻 → 変わらず
if (a.time && b.time) return a.time.localeCompare(b.time);  // 文字で比較
```

**優先順位：**

```
【第1優先】日付で比較
  dateOrder !== 0 なら、ここで return
  
【第2優先】時刻で比較（日付が同じ場合）
  日付が同じ（dateOrder === 0）ときだけ実行
```

#### ステップ2：フィルタリング

```typescript
const patientRecordsWith = patientRecordsGraph.filter(
  (r) =>
    r.vitals?.T != null ||      // 体温がある
    r.vitals?.P != null ||      // 脈拍がある
    r.vitals?.R != null ||      // 呼吸がある
    r.vitals?.SPO2 != null ||   // 酸素飽和度がある
    r.vitals?.SBP != null ||    // 収縮期血圧がある
    r.vitals?.DBP != null,      // 拡張期血圧がある
);
```

**目的：グラフに描画できないデータを除外**

```
【含まれるデータ】
vitals に 1 つ以上の値がある記録

【除外されるデータ】
vitals が空（{}）の記録
vitals が null の記録
```

#### ステップ3：GraphData への変換（重要！）

```typescript
const GraphData = patientRecordsWith.map((r) => ({
  recordKey: r.id,
  xDate: Date.parse(`${r.date}T${r.time || "00:00"}:00Z`),
  date: r.date,
  label: `${r.date} ${r.time || "時刻未記録"}`,
  temperature: r.vitals?.T,
  pulse: r.vitals?.P,
  respiration: r.vitals?.R,
  saturation: r.vitals?.SPO2,
  systolicBloodPressure: r.vitals?.SBP,
  diastolicBloodPressure: r.vitals?.DBP,
  recordId: r.id,
}));
```

**変換前のデータ：**

```typescript
{
  id: "r001",
  date: "2026-11-21",
  time: "08:30",
  vitals: {
    T: 36.5,
    P: 72,
    R: 16,
    SPO2: 98,
    SBP: 120,
    DBP: 80,
  }
}
```

**変換後のデータ：**

```typescript
{
  recordKey: "r001",
  xDate: 1700592600000,  ← グラフの X軸用（重要！）
  date: "2026-11-21",
  label: "2026-11-21 08:30",
  temperature: 36.5,
  pulse: 72,
  respiration: 16,
  saturation: 98,
  systolicBloodPressure: 120,
  diastolicBloodPressure: 80,
  recordId: "r001",
}
```

**xDate の重要性：**

```typescript
xDate: Date.parse(`${r.date}T${r.time || "00:00"}:00Z`)
```

```
【何をしているのか】
日付と時刻を「ISO 8601 形式」に統合
  ↓
Date.parse() で「ミリ秒（数字）」に変換
  ↓
recharts が「この数字の位置に点を打つ」と理解

【例】
入力：2026-11-21 08:30
  ↓
ISO 形式：2026-11-21T08:30:00Z
  ↓
ミリ秒：1700592600000
  ↓
グラフの X軸：この位置に点を打つ
```

## 3. 重要な理解ポイント

### 【sort 関数の返り値と順序の関係】

```
sort((a, b) => {
  return -1  or  0  or  1
         ↑       ↑      ↑
      a前  変わらず  b前
})
```

**負数が返る → a が前に来る**
**0 が返る → 順序変わらず**
**正数が返る → b が前に来る**

### 【日付と時刻の優先順位】

```
if (dateOrder !== 0) return dateOrder;
     ↑
日付が違ったら、ここで return
  ↓
時刻の比較は実行されない

【理由】
日付が重要（優先度高）
時刻は「日付が同じ場合」だけ考慮（優先度低）
```

### 【データ変換のステップ】

```
元のデータ
  ↓
コピー作成（元を保護）
  ↓
ソート（古い順に並べる）
  ↓
フィルタリング（グラフに使える記録だけ）
  ↓
変換（グラフが理解できる形に）
  ↓
グラフ用データ
```
