## 4. コードと理解したこと

### 【学習内容1：dataKey の役割】

**選択コード：**
```typescript
<XAxis
  dataKey={"xDate"}
  type="number"
  scale={"time"}
  domain={["dataMin", "dataMax"]}
  tick={{ fontSize: 10 }}
  tickFormatter={(value) => {
    const date = new Date(value);
    return `${date.getUTCMonth() + 1}/${date.getUTCDate()}`;
  }}
/>
```

**理解したこと：**

```
【dataKey は「誰が使うか」で役割が変わる】

XAxis の dataKey="xDate"
  ↓
「GraphData から xDate プロパティを取り出して、X軸の横方向に使おう」

Line の dataKey="temperature"
  ↓
「GraphData から temperature プロパティを取り出して、折れ線を描こう」

YAxis には dataKey がない
  ↓
「スケール定義だけ。データは取らない」
```

### 【学習内容2：tickFormatter】

**コード：**
```typescript
tickFormatter={(value) => {
  const date = new Date(value);
  return `${date.getUTCMonth() + 1}/${date.getUTCDate()}`;
}}
```

**流れ：**
```
GraphData の xDate: 1700592600000（ミリ秒）
  ↓
recharts が tickFormatter を呼び出す
  ↓
tickFormatter((1700592600000))
  ↓
new Date(1700592600000)
  ↓
「2026-11-21 00:30:00」の Date オブジェクト
  ↓
getUTCMonth() = 10（11月は 0 始まり）
getUTCDate() = 21
  ↓
「11/21」という文字列を返す
  ↓
X軸に「11/21」と表示
```

**重要なポイント：**
- new Date(ミリ秒) でミリ秒 → Date オブジェクトに変換
- getUTCMonth() は 0 始まりだから +1 が必要
- tickFormatter は「グラフの軸に表示する値を加工する関数」

### 【学習内容3：複数の YAxis と yAxisId】

**コード：**
```typescript
<YAxis
  yAxisId="temperature"
  domain={[34, 42]}
  mirror
  tickFormatter={(value) => `${value}℃`}
/>

<YAxis
  yAxisId="pulse"
  domain={[0, 200]}
  orientation="right"
  tickFormatter={(value) => `${value}回/分`}
/>

<Line yAxisId="temperature" dataKey="temperature" stroke="red" />
<Line yAxisId="pulse" dataKey="pulse" stroke="green" />
```

**理解したこと：**

```
【複数の YAxis が必要な理由】

データのスケール：
- 体温：34～42℃
- 脈拍：0～200回/分
- 血圧：0～250mmHg

もし YAxis が 1つ（0～250）だったら：
  ↓
  体温 36.5℃ → Y軸の最下部に小さく表示 ✗ 見えない

複数の YAxis を使うと：
  ↓
  体温用 YAxis：34～42℃ → 体温が大きく表示 ✓ 見やすい
  脈拍用 YAxis：0～200 → 脈拍が大きく表示 ✓ 見やすい
  血圧用 YAxis：0～250 → 血圧が大きく表示 ✓ 見やすい
```

**yAxisId の役割：**
```
YAxis と Line を「ID」で繋ぐ

YAxis(yAxisId="temperature") = 体温用スケール
  ↓
Line(yAxisId="temperature") = 「この YAxis を使ってプロット」
  ↓
「(X位置, Y位置)」に赤い点を打つ
```

### 【学習内容4：Tooltip と recharts の内部処理】

**コード：**
```typescript
<Tooltip
  trigger="click"
  content={({ active, payload }) => {
    if (!active || !payload?.length) return null;
    const activePoint = payload[0]?.payload;
    if (!activePoint) return null;

    const records = getRecordsAtXDate(activePoint.xDate);

    return (
      <div>
        {records.map((r) => (
          <div>
            <div>{r.label}</div>
            <div>体温: {r.temperature}℃</div>
            <div>脈拍: {r.pulse}回/分</div>
          </div>
        ))}
      </div>
    );
  }}
/>
```

**【step 1～5】の流れ：**

```
【step 1】ユーザーがグラフをクリック
「11/21 08:30」の位置をクリック
  ↓
【step 2】recharts が「クリック座標の X値」を検出
「xDate: 1700592600000 だ」と判定
  ↓
【step 3】GraphData から「その xDate と一致する行」を探す
recharts が内部で検索（見えない処理）
  ↓
【step 4】見つかった行を Line の数だけ payload に詰める
payload = [
  { value: 36.5, payload: { xDate: ..., temperature: 36.5, pulse: 72, ... } },
  { value: 72, payload: { xDate: ..., temperature: 36.5, pulse: 72, ... } },
  { value: 16, payload: { xDate: ..., temperature: 36.5, pulse: 72, ... } },
]
  ↓
【step 5】payload[0]?.payload で「クリック位置のデータ」を取得
const activePoint = { xDate: 1700592600000, temperature: 36.5, pulse: 72, ... }
  ↓
getRecordsAtXDate(1700592600000) で再度検索
  ↓
Tooltip に「2026-11-21 08:30 体温: 36.5℃ 脈拍: 72 回/分...」と表示
```

### 【学習内容5：getRecordsAtXDate と GraphData の構造】

**コード：**
```typescript
const getRecordsAtXDate = (xDate: number) => {
  return GraphData.filter((r) => r.xDate === xDate);
};
```

**GraphData の構造：**
```typescript
const GraphData = patientRecordsWith.map((r) => ({
  recordKey: r.id,
  xDate: Date.parse(`${r.date}T${r.time || "00:00"}:00Z`),  // ← X軸
  date: r.date,
  label: `${r.date} ${r.time || "時刻未記録"}`,
  temperature: r.vitals?.T,            // ← Y軸
  pulse: r.vitals?.P,                  // ← Y軸
  respiration: r.vitals?.R,            // ← Y軸
  saturation: r.vitals?.SPO2,          // ← Y軸
  systolicBloodPressure: r.vitals?.SBP,     // ← Y軸
  diastolicBloodPressure: r.vitals?.DBP,    // ← Y軸
  recordId: r.id,
}));
```

**理解したこと：**

```
【GraphData の 1行 = 「その時刻の全データ」】

{
  xDate: 1700592600000,        ← X軸の値
  temperature: 36.5,            ← Y軸の値
  pulse: 72,                     ← Y軸の値
  respiration: 16,              ← Y軸の値
  ...
}

xDate で検索
  ↓
「xDate が 1700592600000 と一致する行」を探す
  ↓
その行のすべてのデータ（X軸とY軸）が返ってくる
  ↓
「この時刻は、温度 36.5℃、脈拍 72 回/分、…」という全情報が手に入る
```

**なぜ Y軸のデータも一緒に手に入るのか：**
```
「X軸で検索」ではなく
「『その時刻の完全な情報』を検索」

GraphData の 1行が「時刻」と「その時刻のすべてのデータ」を持つから
```
